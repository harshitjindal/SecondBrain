1. In C++, the sort() function provided by STL uses a hybrid of Quick Sort, Heap Sort and Insertion Sort, with a worst case space complexity of O(log⁡n)
2. binary_search(v.begin(), v.end(), element) returns 1 if found, else 0.
3. lower_bound(v.begin(), v.end(), element) on sorted container like sorted vector or set always returns iterator to first value >= element. If element is larger than all elements in v, then returns v.end()
4. upper_bound(v.begin(), v.end(), element) on sorted container like sorted vector or set always returns iterator to first value > element. If element is larger than all elements in v, then returns v.end(). Time complexity for both upper_bound and lower_bound is log(n)
5. Min / Max element: *(min_element(v.begin(),v.end())), can also be used on subarray
6. Sort: used like sort(v.begin(), v.end()) or sort(a, a+n). Inplace sorting. To get descending order: sort(v.begin(), v.end(), greater<int>) or use a custom comparator without parentheses. Partial sorting also allowed like sort(v.begin()+5, v.begin()+9)
	1. The custom comparator must always return bool, and should be a static function if within a class declaration
		1. Eg to sort pairs based on second element: 
			1. bool comp(pair<int, int> p1, pair<int, int> p2) {
				1. if (p1.second < p2.second) return true;
				2. else return false;
			2. }
		2. Or use a lambda function of format: sort(v.begin(), v.end(), [](int a, int b) { return a < b; })
7. Reverse: reverse(v.begin(), v.end())
8. __builtin_popcount(n) or __builtin_popcountll(nll) to count number of set bits in an int or long_long respectively. Eg: int 7 (bin 111) would return 3.
9. Next_permutation:String s = “123”;Do {	Cout << s << endl;} while (next_permutation(s.begin(), s.end()));
10. HCF can be used with __gcd(), and LCM is available in c++20 as std::lcm()
11. to_string(int): can be used to convert int or long long to string. Number of digits in a number is upper bound O([log10(n)] + 1)
12. String reversal can be done with inbuilt reverse(str.begin(),str.end()) or with str = string(str.rbegin(),str.rend()); Notice rbegin() and not begin().
	1. Note: reverse() does NOT return the reversed string, it makes changes in place, which is why it should NOT be used like cout << reverse(all(str)) << endl; It will likely throw an error this way. Do reverse(all(str)) first, and then do cout << str << endl;
13. log10() and log() can be used and have base of 10 and e, respectively
14. X = a^(log X to the base a): X = alog a(X)
15. exp(x) is e^x
