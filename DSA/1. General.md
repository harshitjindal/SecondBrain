4. HCF / LCM
	1. HCF x LCM = Product of two numbers
	2. HCF = LCM = number if the numbers are equal
	3. HCF(0, number) = number
	4. We can use Euclid’s Division Algorithm to find HCF of two numbers. It works because if a = b(q) + r, then HCF (a, b) = HCF (b, r), because if k divides ‘a’ and ‘b’, then if we divide equation by ‘k’, a/k is an integer, which means RHS must also be an integer, ie: ‘r’ must also be divisible by ‘k’
